# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [26.10.2] - 2026-10-20

### Added

- Project stack badge in the README.
- VibeDeck project setup (`vibedeck.json` and `.vibedeck/`).

### Changed

- Notepad++ is now a single themeless icon (`NotepadPlusPlus.svg`) instead of separate dark and light icons.
- Refreshed the JetBrains IDE icons: AppCode, Aqua, CLion, DataGrip, DataSpell, GoLand, IntelliJ IDEA, PhpStorm, PyCharm, Rider, RubyMine, RustRover and WebStorm.
- Logos now fill the tile, clipped to its rounded corners, for Apple Music, Citty, Devbox, Farcaster, Hacker News, Inquirer, KakaoTalk, Ruff, Todoist, Trello and WezTerm.
- Brand-colored tile for Things, resized Victory logo and simplified SigNoz icon.

### Removed

- `NotepadPlusPlus-Dark.svg` and `NotepadPlusPlus-Light.svg`.
